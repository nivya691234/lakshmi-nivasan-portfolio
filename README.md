# Lakshmi Nivasan B — Portfolio Rebuild

This version is deliberately rebuilt without React/icon-library dependencies that caused the earlier page to break.

## Run

```bash
npm install
npm run dev
```

Then open the URL Vite prints, normally `http://localhost:5173`.

## What changed

- Custom animated green engineering watch interface inspired by the *idea* of a transformation watch, without using alien characters or copyrighted Ben 10 artwork.
- Startup watch boot sequence with scan line, rotating rings and progress.
- Interactive watch mode selector for Work / DevOps / Tools / Proof / Learn / Connect.
- Fast moving technology-logo stream.
- Real project GitHub/Live links.
- Real certificate proof images and one-page PDF files packaged in `public/proofs/`.
- Proof cards open the actual certificate image and the original one-page PDF.
- Dark/Day mode.
- Responsive layout.

## Important

All certificate preview images in this build were rendered from certificate files already available in the conversation/library sources. No blank proof placeholders are intentionally used.
